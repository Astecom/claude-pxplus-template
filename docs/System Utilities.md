#  

**System Utilities** |  **_ _**  
---|---  
  
PxPlus comes equipped with several utilities that are not, strictly speaking, part of the language, but provide various design, configuration, maintenance and diagnostic services within the development environment. These utilities help to make it easier to create and manage PxPlus programs, files and directories.

Use the links below (in alphabetical order) to access information for a particular utility:

**Utility** |  **Description**  
---|---  
**[Bulk Program Scan Utility](Bulk%20Program%20Scan%20Edit.md)** |  Used to perform one or more string searches and/or replacements against a series of programs.  
**[Command Line Utilities](PxPlus%20User%20Guide/Getting%20Started/System%20Utilities/Command%20Line%20Utilities.md)** |  A set of system utilities that may be called directly from the Command line.  
**[CSV File Import Utility](CSV%20File%20Import%20Utility/Introduction.md)** |  Used to import data in a CSV (_Comma Separated Values_) or TSV (_Tab Separated Values_) file directly into PxPlus.  
**[Database Export Utility](Data%20Dictionary/Data%20Dictionary%20Maintenance/Database%20Export.md)** |  See **[Calling Export Actions Programmatically](Data%20Dictionary/Data%20Dictionary%20Maintenance/Database%20Export.htm#Mark6)** for detailed information on invoking and applying this utility programmatically. _(The Database Conversion Utility was added in PxPlus 2019 and renamed to Database Export Utility in PxPlus 2023.)_  
**[Database Import Utility](Data%20Dictionary/Data%20Dictionary%20Maintenance/Database%20Import.md)** |  See **[Calling Import Actions Programmatically](Data%20Dictionary/Data%20Dictionary%20Maintenance/Database%20Import.htm#call_routines)** for detailed information on invoking and applying this utility programmatically. _(The Database Import Utility was added in PxPlus 2023.)_  
**[File Update Utility](File%20Update%20Utility.md)** |  Used to view, modify and update the records within a selected data file, one record at a time.  
**[File View Utility](File%20View%20Utility.md)** |  Used to view, but not modify, the records within a selected data file.  
**[Program Compare Utility](Program%20Compare.md)** |  Used to compare two versions of an existing program file on a line-by-line basis to detect any differences.  
**[Project Maintenance](Project%20Maintenance.md)** |  Used to add one or more tasks of various types to a predefined project, as well as remove tasks -- _all at one time_. _(The Project Maintenance utility was added in PxPlus 2014 - Feature Pack 1.)_  
**[System Utilities](PxPlus%20User%20Guide/Getting%20Started/System%20Utilities/Graphical%20Utilities.md)** |  Launches a window that provides menu bar and toolbar options for accessing graphical utilities.  
**[Toolkit for Conversion from BBx®](conv.bbx/overview.md)** **[Toolkit for Conversion from Thoroughbred®](conv.tbd/overview.md)** |  Conversion tools and utilities to assist in moving from other Business Basic environments to PxPlus.  
**[Visual Dictionary Utility](Visual%20Dictionary/Visual%20Dictionary%20Introduction.md)** |  Used to provide a simple means by which a data dictionary can be defined for a data file.
