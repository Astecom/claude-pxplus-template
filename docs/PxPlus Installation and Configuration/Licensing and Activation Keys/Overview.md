##  Licenses

PxPlus offers **_Base_** , **_Professional_** and **_Web_** licenses for commercial use. A separate **[Developer License](Overview.htm#devlicense)** is available for development and testing use only.

**_Base_** |  A core license that provides the essential components required for business applications.  
---|---  
**_Professional_** |  A license designed for Client-Server environments that supports the following: WindX Plug-In (per user), PxPlus SQL Server, and ODBC Driver.  
**_Web_** |  A full-featured license designed for Web implementation (i.e. **[Webster+ Web Development Toolkit](../../Webster/Webster.md)**) and internet-based applications and services.  
  
For a list of components included with the _Base_ , _Professional_ and _Web_ licenses, refer to the **[Development Environment](https://home.pvxplus.com/our-products.htm#development)** page on the PVX Plus website.

Each PxPlus license requires a unique Serial Number and Activation Key. An activation utility is included in the PxPlus download to assist with entering and recording this information.

To obtain product and licensing information, place an order, or find the nearest reseller, contact PVX Plus Sales at **[sales@pvxplus.com](mailto:sales@pvxplus.com)**.

##  Developer License

A **_Developer license_** is a 2-user Web license available for purchase at a nominal fee. It offers developers a cost-effective way to access the **_latest PxPlus version_** , tools and features.

This license is issued to developers and is valid for 1 year. At the end of 1 year, the license can be renewed for another year or allowed to expire.

This license allows authorized developers to install and use PxPlus solely within a controlled development environment for activities such as coding, debugging and testing.

**_Key Benefits_**

The Developer license offers the following benefits:

  * Available as a 2-user **_Web_** license
  * Is always current with the latest PxPlus release
  * Supports Windows and UNIX/Linux installations
  * Can be installed on more than one developer-controlled machine



**_Conditions of Use_**

The Developer license is subject to the following restrictions, which must be strictly observed:

  * It must not be resold, redistributed, or used in any production environment.
  * It cannot be made available or accessible to end users.
  * It cannot be used to run live customer applications.
  * It does not permit PxPlus or any PxPlus-based applications to be resold or commercially distributed without purchasing appropriate licensing from PVX Plus.



#### **Important Note:**  
**_Failure to comply with these restrictions may result in termination of the license._**

For more information or to purchase a Developer license, contact PVX Plus Sales at **[sales@pvxplus.com](mailto:sales@pvxplus.com)**.

##  Continuous Care Program (CCP)

The **_Continuous Care Program_** _ **(CCP)**_ subscription guarantees access to the latest enhancements, tools, and security updates. The initial CCP term is for 1 year, after which it will continue indefinitely until it is discontinued either by PVX Plus or the PVX Plus customer.

Refer to the **[Continuous Care Program (CCP)](https://home.pvxplus.com/our-products.htm#ccp)** page on the PVX Plus website for details.

**_CCP Eligibility and Enrollment_**

CCP is available for all serial numbers (licenses). Serial numbers may be enrolled in a CCP plan:

> (a) when a new license is purchased, **_OR  
> _**(b) when an existing license is upgraded to the latest version.

To obtain more information or to join this program, contact PVX Plus Sales at **[sales@pvxplus.com](mailto:sales@pvxplus.com)**.

**_Access to Updates_**

Customers enrolled in CCP receive full access to all PxPlus software updates and applicable major/minor PxPlus releases for each enrolled serial number. Updates apply only to options covered by the CCP fee for a given serial number and may not be available for serial numbers not enrolled in CCP.

**_No Administrative Fees for License Moves_**

If a registered PxPlus license needs to be moved to a new machine or a manual reset is required, no administrative fee will apply if that license is enrolled in an active CCP plan.

## Modes of Activation

PxPlus supports three modes of activation: **_Temporary_** , **_Permanent_** and **_Demo_**.

**_Temporary_** |  Each new PxPlus license includes a **_temporary_** activation that allows the product to run for up to 30 days. When you purchase a license, you receive:

  * A Serial Number
  * An Activation Key based on your PxPlus product and user count

During installation, you are prompted to enter your Activation Key. This key allows you to run PxPlus for 30 days. Before the 30-day period ends, you must register PxPlus online (see **[Online Registration](Online%20Registration.md)**) or complete the **[Manual Activation](Manual%20Activation.md)** process to enable permanent activation and ensure uninterrupted use. If the online registration is not completed within this 30-day period, PxPlus will no longer start. Warning messages begin appearing 7 days before the temporary activation expires.

#### **Important Note:**  
A temporary activation may also be used for **_emergency reinstallation_** in case of a system failure.  
  
---|---  
**_Permanent_** |  A **_permanent_** activation registers a licensed PxPlus product on a specific machine. This license may or may not include an expiry date. Each permanent activation requires a new permanent key, which is generated using the system information collected during installation. A valid permanent activation depends on the following criteria:

  * System ID
  * Machine Class Number
  * Product Serial Number
  * Number of licensed users
  * Expiry date (if applicable)

This information ensures that the activation is tied to the original system configuration. Once a permanent activation is recorded, the software cannot be moved to another machine unless the license explicitly allows it. If the activation file is moved or deleted, a new permanent key must be issued to re-establish the activation at its new location. The permanent key is created by running the PxPlus **[Online Registration](Online%20Registration.md)**. The key is stored in the **[ACTIVATE.PVX](../../PxPlus%20System%20Programs%20and%20Files/System%20Activation%20Information/Overview.md)** activation keys file in the default system location. If your system is not connected to the internet or you are unable to complete online registration, you must complete the **[Manual Activation](Manual%20Activation.md)** process, which requires submitting a Helpdesk ticket to PVX Plus Support. An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Overview.htm#ccp)** and for unsupported versions.

#### **Important Note:**  
**_For PxPlus versions 10 and prior:_** Online activation is no longer supported due to required security updates. For the steps for manual activation, see **[Manual Activation (v10 and prior)](Manual%20Activation_v10.md)**.  
  
**_Demo_** |  A **_demo_** activation allows you to "test drive" the PxPlus Web license for 30 days. See [**Licenses**](Overview.htm#licenses) for more information. During this 30-day period, the following restrictions apply:

  * A "nag" message appears every 30 minutes.
  * The system is limited to a single user.
  * Files are limited to a maximum of 5,000 records.

To continue using PxPlus after the 30-day period, you must purchase a **_permanent_** license. To purchase a license or obtain more information, contact PVX Plus Sales at [**sales@pvxplus.com**](mailto:sales@pvxplus.com).

#### **Note:**  
Due to the limitations of the Demo version, purchasing a [**Developer License**](Overview.htm#devlicense) may provide a more effective way to evaluate PxPlus.  
  
When you purchase a PxPlus product, you receive one (or more) 25-character activation key(s). If you purchase the complete PxPlus Development Suite, you will receive one key for the core PxPlus product, plus additional key(s) for any add-ons purchased.

During installation, you are prompted to enter the product **_Activation Key_** included in your **[Product Activation Email](../Getting%20Started.htm#email)**. This Activation Key activates PxPlus for **30** days.

Before this 30-day period expires, you must complete the **[Online Registration](Online%20Registration.md)** process for your product (when connected to the internet) to enable permanent activation.

If you are unable to complete the online registration, you must complete the **[Manual Activation](Manual%20Activation.md)** process. An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Overview.htm#ccp)** and for unsupported versions.

If your product is not registered before the 30-day period ends, PxPlus will no longer start.

##  Concurrent User Limits

Each registered PxPlus license specifies **_both_** the highest PxPlus version it is authorized to run **_and_** the maximum number of concurrent users allowed to access the license at any given time.

When the maximum number of concurrent users has been reached, any new users attempting to start PxPlus will receive a warning message indicating that the user limit has been exceeded, and their request to start PxPlus will be denied. Beginning with PxPlus 2019, any user session rejected due to exceeding the user limit will be logged in the system log file. See **[PxPlus Log File](../../PxPlus%20User%20Guide/Development%20Tools/Error%20Handling%20and%20Debugging/Additional%20Debugging%20Procedures%20and%20Facilities.htm#logfile)**.

Concurrent users are generally defined as the number of different end-user systems. Where possible, the system attempts to determine whether a user on the same workstation is running multiple instances of the same version of PxPlus. If it is possible to verify that multiple sessions are being used on the same workstation by the same user, the multiple instances will be considered as only a single concurrent user. Generally, this is only possible when using WindX and any of the PxPlus Thin-Client server interfaces.

If the user count needs to be increased, see **[Increasing User Count](Increasing%20User%20Count.md)**.

_(User limit exceeded system logging was added in PxPlus 2019.)_
