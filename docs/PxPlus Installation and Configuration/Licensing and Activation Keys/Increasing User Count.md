# License Management

**Increasing User Count**|   
---|---  
  
To increase the user count (add more licenses), you must first contact PVX Plus Sales at **[sales@pvxplus.com](mailto:sales@pvxplus.com)**.

##  For PxPlus Version 11 and Later

Once PVX Plus Sales confirms the user count increase, enter **RUN "*plus/reg/net"** from the PxPlus Command line to update the user count (for versions supporting online activation).

If your system is not connected to the internet or if you are unable to complete online registration, you must submit a Helpdesk Ticket to PVX Plus Support to request a manual activation. For steps, see **[Manual Activation](Manual%20Activation.md)**. An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Overview.htm#ccp)** and for unsupported versions.

##  For PxPlus Version 10 and Prior

Online registration does **_not_** support user count increases (additional licenses). You **_must_** re-register by submitting a Helpdesk ticket to PVX Plus Support to request new permanent keys for the **_same System ID and Class_** shown on the Activation window.

Before contacting PVX Plus Support, see **[Manual Activation (v10 and prior)](Manual%20Activation_v10.md)** and follow the steps for manual activation (permanent keys).

If, during the activation process, the activation file cannot be found, a message will display. If this happens, see **[Activation Messages](../Troubleshooting/Activation%20Messages.md)** for more information.
