# PxPlus Installation and Setup

**Activation and Registration**|   
---|---  
  
PxPlus includes a built-in, internet-based **[Online Registration](Online%20Registration.md)** system to register your PxPlus product and enable **[Permanent Activation](Overview.htm#permanent)**. Online registration is done after a new PxPlus installation (once you have entered the temporary Activation Key from your **[Product Activation Email](../Getting%20Started.htm#email)**) and when you upgrade your PxPlus product.

Online registration runs **_automatically_** when:

  * an activation changes
  * a new **_pxplus.exe_** is detected
  * a new PxPlus installation is run for the first time



Running ***plus/reg/net** from the PxPlus Command line also registers your product, typically when upgrading PxPlus.

If the system on which PxPlus is installed is not connected to the internet or if you are unable to complete the online registration, you must complete the **[Manual Activation](Manual%20Activation.md)** process. An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Overview.htm#ccp)** and for unsupported versions.

#### **Important Note:**  
The registration process and activation keys are valid **_only_** for the system on which PxPlus is installed.
