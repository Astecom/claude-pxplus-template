# License Management

**Moving PxPlus License to New System _(v10 and prior)_**|   
---|---  
  
#### **Important Note:**  
The process below will **_only_** transfer your PxPlus license. It will **_not_** transfer your application programs and/or files. You will need to do these separately.

Follow the steps below to move your registered license **_(PxPlus version 10 and prior)_** to a new machine when necessary. An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Overview.htm#ccp)** and for unsupported versions.

Before you begin, ensure that you have the Serial Number and Activation Key for your license so you can install it on the new system.

1. |  **Remove Old Activation** Remove the old activation from the original system using the steps below. **_For Windows:_**    1\. Open the **pxpwactv.exe** file from the PxPlus installation directory.  
   2\. Click the **Reset All** button.   
   3\. Click **Done**. **_For Unix/Linux:_**    1\. Open **/pxplus/lib/ACTIVATE.PVX**. (See **[ACTIVATE.PVX](../../PxPlus%20System%20Programs%20and%20Files/System%20Activation%20Information/Overview.md)**.)  
   2\. Remove the activation file. The current activation will be removed from the device.

#### **Important Note:**  
Online activations for **_PxPlus version 10 and prior_** (Windows) are no longer supported due to required security updates.  
  
---|---  
2. |  **Install PxPlus** Install PxPlus on the new system. For Windows, see **[Download and Installation (Windows)](../Installation%20Instructions/Windows%20Installation.md)**. For UNIX/Linux, see **[Download and Installation (UNIX/Linux)](../Installation%20Instructions/UNIX%20and%20Linux%20Installation.md)**.  
3. |  **Complete Manual Activation** For the steps to complete the Manual Activation process, see **[Manual Activation (v10 and prior)](Manual%20Activation_v10.md)**.
