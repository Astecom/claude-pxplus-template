# Activation and Registration

**Manual Activation**|   
---|---  
  
If your system is not connected to the internet or if you are unable to complete the **[Online Registration](Online%20Registration.md)**, you will need to submit a Helpdesk ticket to PVX Plus Support to request manual activation (permanent keys). An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Overview.htm#ccp)** and for unsupported versions.

Follow the steps below for manual activation:

1. |  **Find Your System ID and Class Information** Before contacting PVX Plus Support, find your System ID, Machine Class Number and Serial Number. To do this, use **_one_** of the following methods (depending on the operating system): |  **_Windows:_** |  Open the **pxpwactv.exe** file in the PxPlus installation directory  
---|---  
**_UNIX/Linux:_** |  Enter this command:  **pxpreg -v**  
  
      
  
2. |  **Submit a Helpdesk Ticket** Submit a Helpdesk ticket to PVX Plus Support at **[https://helpdesk.pvxplus.com](https://helpdesk.pvxplus.com/)**. Select the **_Open a New Ticket_** button or top menu bar option. Enter your support request for manual activation and include the following:

  * A valid email address
  * Your full name
  * System ID
  * Machine Class Number
  * Product Serial Number **_(Do not include license Activation Keys)_**



#### **Important Note:**  
To help resolve your issue as quickly as possible, all requested information must be provided. Missing details will result in delays.  
  
3. |  **Receive Activation Key(s) from PVX Plus** PVX Plus will generate and email your Activation Key(s) for **_permanent_** activation.  
4. |  **Record Activation Key(s)** When you receive your Activation Key(s), record the key(s) on your system by using **_one_** of the following methods (depending on the operating system): |  **_Windows:_** |  Open the **pxpwactv.exe** file in the PxPlus installation directory  
---|---  
**_UNIX/Linux:_** |  Enter this command:  **pxpreg -k  _keyvalue_** (where **_keyvalue_** is the key you have been given)  
  
After the key is entered, click the **Record Key**  button. Registration information appears in the white box below the key. Repeat this process if you have multiple keys.

When finished entering all the keys, click **Done**.  
  
5. |  **Restart PxPlus** Restart PxPlus to complete the registration.
