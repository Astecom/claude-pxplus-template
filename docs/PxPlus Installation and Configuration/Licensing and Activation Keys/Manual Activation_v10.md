# Activation and Registration

**Manual Activation _(v10 and prior)_**|   
---|---  
  
#### **Important Note:**  
Online activations for **_PxPlus version 10 and prior_** (Windows) are no longer supported due to required security updates.

Follow the steps below for manual activation (permanent keys). An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Overview.htm#ccp)** and for unsupported versions.

1. |  **Find your System ID and Class Information** Before contacting PVX Plus Support, find your System ID and Machine Class Number. To do this, use **_one_** of the following methods: Open the **_old_** activation utility **pvxwactv.exe** in the PxPlus installation directory.  
  
**_OR_**  
  
Open the **_new_** activation utility **pxpwactv.exe** in the PxPlus installation directory (requires new 25-digit keys).  
  
**_OR_**  
  
From the new screen, select the option to open the **_old_** activation screen. |  |   
---|---  
2. |  **Submit a Helpdesk Ticket** Submit a Helpdesk ticket to PVX Plus Support at **[https://helpdesk.pvxplus.com](https://helpdesk.pvxplus.com/)**. Select the **_Open a New Ticket_** button or top menu bar option. Enter your support request for manual activation and include the following:

  * A valid email address
  * Your full name
  * System ID
  * Machine Class Number
  * Product Serial Number **_(Do not include license Activation Keys)_**



#### **Important Note:**  
To help resolve your issue as quickly as possible, all requested information must be provided. Missing details will result in delays.  
  
3. |  **Receive Activation Key(s) from PVX Plus** PVX Plus will generate and email your Activation Key(s) for **_permanent_** activation.  
4. |  **Record Activation Key(s)** When you receive your permanent Activation Key(s), record the key(s) on your system by using **_one_** of the following methods (depending on the operating system): |  **_Windows:_** |  Open the **_old_** activation utility **pvxwactv.exe** in the PxPlus installation directory.  
  
**_OR_**  
  
Open the **_new_** activation utility **pxpwactv.exe** in the PxPlus installation directory (requires new 25-digit keys).  
  
**_OR_**  
  
From the new screen, select the option to open the **_old_** activation screen.  
---|---  
**_UNIX/Linux:_** |  Enter this command:  **pxpreg -k  _keyvalue_** (where **_keyvalue_** is the key you have been given)  
  
After the key is entered, click the **Record Key** button. Registration information appears in the white box below the key. Repeat this process if you have multiple keys.

When finished entering all the keys, click **Done**.  
  
5. |  **Restart PxPlus** Restart PxPlus to complete the registration.
