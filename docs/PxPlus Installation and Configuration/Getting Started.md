# PxPlus Installation and Setup

**Getting Started** |  **_ _**  
---|---  
  
This page outlines the supported operating systems, explains the information included in your product activation email, and provides an overview of the key steps in the download, installation and activation process.

This information should be reviewed first to help ensure a smooth installation and prepare you for the steps that follow. It should be reviewed by system administrators responsible for installing and maintaining PxPlus, as well as by application developers who use PxPlus to build or integrate their applications.

## Supported Operating Systems

PxPlus is a feature-rich development language designed to run on all major operating systems:

     **_Windows:_**  
          32-bit  
          64-bit

     **_Unix or Unix-like Systems:_**  
          MacOS  
          AIX

     **_Linux Systems_** :  
          Debian  
          Redhat  
          SUSE  
          Ubuntu

To find out which versions of these operating systems are supported, follow these steps:

1. |  Refer to the **[Downloads](https://home.pvxplus.com/downloads.md)** page on the PVX Plus website.  
---|---  
2. |  Scroll to the **Download Center** section where you will find a list of recent PxPlus versions.  
3. |  Click one of the listed versions to view the details for that update.

## Overview of Key Steps

This table presents an overview of the key steps in the download, installation and activation of PxPlus. Review these steps to familiarize yourself with the overall process.

1. |  **Download and install PxPlus for your operating system** Details are provided on the following pages: **[Download and Installation (Windows)](Installation%20Instructions/Windows%20Installation.md)**  
**[Download and Installation (UNIX/Linux)](Installation%20Instructions/UNIX%20and%20Linux%20Installation.md)**  
---|---  
2. |  **Start using PxPlus during the temporary activation period** Your new PxPlus installation includes a **[Temporary](Licensing%20and%20Activation%20Keys/Overview.htm#temporary)** 30-day activation. Before the 30 days ends, you must register your product with PVX Plus and enable **[Permanent](Licensing%20and%20Activation%20Keys/Overview.htm#permanent)** activation. Warning messages begin appearing 7 days before the temporary activation expires. For information on starting PxPlus, see **[Launching PxPlus](Launching%20PxPlus/Overview.md)**.  
3. |  **Register PxPlus online** Register PxPlus online. Your system must be connected to the internet. See **[Online Registration](Licensing%20and%20Activation%20Keys/Online%20Registration.md)**. On Windows, a quick and easy way to register is to double click the **_Register_** desktop shortcut created after installation. For more information, see **[Windows Installation](Installation%20Instructions/Windows%20Installation.htm#shortcuts)**.  
4. |  **Request manual activation (only if necessary)** If you are unable to register PxPlus online (i.e. your system is not connected to the internet or online registration is not available), submit a Helpdesk ticket to PVX Plus Support to request manual activation. For steps, see **[Manual Activation](Licensing%20and%20Activation%20Keys/Manual%20Activation.md)**. An administrative fee may apply for licenses not enrolled in the **[Continuous Care Program (CCP)](Licensing%20and%20Activation%20Keys/Overview.htm#ccp)** and for unsupported versions.  
5. |  **Customize PxPlus** You can optionally customize your PxPlus environment to suit your development and application needs. See **[Customizing PxPlus](Customizing%20PxPlus/Overview.md)**.
