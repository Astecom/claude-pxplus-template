# PxPlus Installation and Setup

**Download and Installation (Windows)** |  **_ _**  
---|---  
  
##  Before Downloading

Review the checklist below to help ensure an efficient download and installation:

  * Have your PVX Plus [**Product Activation Email**](../Getting%20Started.htm#email) readily available, as it contains your product Activation Key(s).
  * Verify that your system is connected to the internet for [**Online Registration**](../Licensing%20and%20Activation%20Keys/Online%20Registration.md). If it is not, be prepared to perform the [**Manual Activation**](../Licensing%20and%20Activation%20Keys/Manual%20Activation.md) process.
  * Determine whether you need the 32-bit or 64-bit version of PxPlus. In most cases, the 64-bit version is recommended. Choose the 32-bit version only if you need to interface with an external 32-bit component.
  * Review the steps below for [**Downloading**](Windows%20Installation.htm#download) and [**Installing**](Windows%20Installation.htm#install) PxPlus.



If you need assistance, submit a Helpdesk ticket to PVX Plus Support at [**https://helpdesk.pvxplus.com**](https://helpdesk3.pvxplus.com/). Select the **_Open a New Ticket_** button or top menu bar option.

Enter your support request and include the following:

  * A valid email address
  * Your full name
  * Serial Number of the PxPlus license related to the issue **_(Do not include the license Activation Keys)_**
  * PxPlus versions and types of equipment
  * Description of the problem and symptoms (only one problem description per ticket)



#### **Important Note:**  
To help resolve your issue as quickly as possible, all requested information must be provided. Missing details will result in delays.

##  Downloading PxPlus

Follow these steps for downloading PxPlus (Windows):

1. |  Open the **[Downloads](https://home.pvxplus.com/downloads.md)** page on the PVX Plus website.  
---|---  
2. |  Scroll to the **Download Center** section, where you will find a list of recent versions (including the latest release) and additional components.  
3. |  Click the version required for your Windows operating system.  
4. |  A new page is displayed. Select the desired installation package (32-bit or 64-bit).

#### **Important Note:**  
It is recommended that you use the **_.exe_** file (32-bit or 64-bit) rather than the **_.zip_** package.  
  
If you must use the **_.zip_** file, ensure that you **_do not_** copy the **_.zip_** file or overwrite any existing files when restoring its contents in the target directory.  
  
5. |  Once the file has been downloaded, you are ready to install PxPlus.  
  
##  Installing PxPlus

PxPlus should be installed in a clean target directory. It is strongly recommended that you create a dedicated sub-directory under the "PVX Plus Technologies" parent folder. You may choose a different location if preferred.

#### **Helpful Tip:**  
To automatically populate the Activation Key during installation, follow these steps:  
  
  1\. Before starting the installation, open your **[Activation Email](../Getting%20Started.htm#email)** from PVX Plus.  
  2\. Copy the 25-character Activation Key.  
  3\. Start the PxPlus installation.  
  4\. When prompted for the Activation Key, the copied key will be automatically inserted.

Follow these steps for installing PxPlus (Windows):

1. |  Run the **_.exe_** file to start the installation wizard.       
---|---  
2. |  After a few moments, the **Welcome** panel displays. Click **Next** to continue.  
  
      
3. |  This panel presents the license agreement. Read the agreement carefully. To continue, select the "I accept " option and click **Next**.       
4. |  On the **Customer Information** panel, enter the **User Name** and **Organization**. Click **Next** to continue.       
5. |  On the **Destination Folder** panel, specify the destination folder for your PxPlus installation.      A default destination folder is provided. You can accept this folder or specify a different location. To continue with the default destination folder, click **Next**. To specify a different location, click **Change**. The **Change Current Destination Folder** panel opens.     In the _Folder name_ field, enter the pathname of the folder you want to use. To make this easier and faster, you can use the two buttons that are available. Click _Up One Level_ to move up one directory or click _Create New Folder_ to add a new folder in the current directory. When you are done, click **OK**. If you do not want to change the destination folder, click **Cancel**.  
6. |  You are returned to the previous **Destination Folder** panel. Verify that the destination folder displayed is correct. If it is correct, click **Next**. If it is not correct, click **Change** again and specify the desired folder.  
7. |  Before starting the installation, select which of the two user options will have access to the PxPlus installation. **_The installation begins once a user option is selected._**      **_Before_**  **_choosing a user option_** , you can review or change your previous settings by clicking **Back**. To exit the installation wizard without continuing, click **Cancel**.  
8. |  Once the installation begins, the progress bar indicates the status (i.e. copying new files, creating shortcuts, etc.).            
9. |  At the end of the installation, the **PxPlus product keys and registration** panel is displayed. This panel shows the **Registered user name** and prompts you to enter your 5-segment product key(s). Enter the **Activation Key** from the email (if you did not previously copy it). Click the **Record Key** button. Registration information appears in the white box below the key entry field. If you cannot perform online activation, or if you need to run PxPlus with a temporary activation for a period of time, and you received two Activation Keys, enter the **PxPlus Activation Key** and click **Record Key** again. When finished, click **Done**.       
10. |  The installation wizard is finished. Click **Finish** to exit the wizard.       
11. |  On your  desktop, two new shortcuts have been added for the PxPlus version installed: |  |  This shortcut runs the PxPlus [**Online Registration**](../Licensing%20and%20Activation%20Keys/Online%20Registration.md). Double clicking it displays a message asking whether you would like to run the online registration. An internet connection is required.  
---|---  
|  This shortcut launches the [**PxPlus IDE**](../../PxPlus%20IDE/Introduction%20to%20PxPlus%20IDE.md) (Integrated Development Environment).  
12. |  Your new PxPlus installation includes **_temporary_** activation, which gives you **_30 days_** to register your product with PVX Plus and enable **_permanent_** activation. When PxPlus is run for the first time after installation, the system checks whether the software is registered and prompts you to register if it is not. If _Yes_ is selected, the system will connect to the internet to complete the registration. A quick and easy alternative is to double click the **_Register_** desktop shortcut.

#### **Note:**  
It is strongly recommended that you register your software immediately after installation to ensure uninterrupted use of PxPlus.
