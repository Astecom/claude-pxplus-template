# How To Tutorials

**How to Use the NOMADS Environment Maintenance Utility**|   
---|---  
  
The **[NOMADS Environment Maintenance](../NOMADS%20Graphical%20Application/Maintain%20Nomads%20Environment.md)** utility provides a simple grid interface for setting **%NOMADS** properties for your application. The utility gives you access to all of the **%NOMADS** properties. It presents a list of properties that can be sorted alphabetically by category or by property. It can also be sorted according to whether the property has been set.

Each property value can be entered by selecting a check box or a drop box, picking a value from a lookup, or entering a value in the grid. Property values can also be entered as expressions for added flexibility. The values are stored in a Settings file, and once the **%NOMADS** object is instantiated, all of the settings are applied.

**_How to Set %NOMADS Properties_**

These steps show you how to set %NOMADS properties using this utility.

1. |  From the IDE Main Launcher, expand the _Graphical Application Builder (NOMADS)_ category. Select the _Maintain NOMADS Environment_ task.  
---|---  
2. |  The **Maintain NOMADS Environment** window displays.       
3. |  As you navigate through each property, the **Property Description** (below the grid) displays a brief overview, which includes examples when applicable. In this example, the description for the Chart$ property is displayed.  
4. |  This list can be sorted by **Category** or by **Property** to make it easier to find the properties you want to set. This list is initially sorted by the first column, **Category** , in ascending order (indicated by the up triangle). To sort this column in descending order, click the **Category** column heading. The down triangle indicates it is in descending order.                                     To sort by property, click the **Property** column heading.                                     
5. |  You can also sort this list according to whether the property has been set by clicking on the **Set** column heading. To set a property, select the **Set** check box, and then select or enter the value that is appropriate for the selected property in the **Value/Expression** column. To enter an expression, select the **Exp** check box, and then enter the expression for the selected property in the **Value/Expression** column.

#### **Note:**  
If a value or expression is entered first, the **Set** check box will automatically be selected.  
  
6. |  To save the entries, click _OK_ or _Apply_. Click _OK_ if you want to exit the utility after saving. Click _Apply_ if you do not want to exit the utility after saving.  
  
**_Other Features_**

  |  _Display Settings_ |  Displays the last saved contents of the Settings file, which is used to save the values entered in the grid.  
---|---|---  
  |  _Copy To_ |  Launches the **Copy Settings File** window for copying the current Settings file to another directory.  
  |  _Reset_ |  Clears the contents of the Settings file so that properties can be defined again from the beginning.
