# Control Object Properties

**FieldHeight** |  **_Height of Drop Box Input Area and Drop Section_**  
---|---  
  
## Description

Defines the height (in pixels) of the drop box input area and drop section.

When set, the same height is applied to each line in the drop section, and the overall height of the expanded control is affected. Text is centered vertically within the control.
