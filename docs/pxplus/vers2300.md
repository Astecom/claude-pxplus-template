# PxPlus Releases

**PxPlus 2026 (version 23.00)** |  **_May 2026_**  
---|---  
  
**PxPlus 2026 expands the .NET Interface and the Visual Studio Code Extension with new capabilities, adds the ability to modernize your UI with rounded controls, and updates security.**

|  Staying current with the latest security is essential for protecting sensitive data and systems against constantly evolving cyber threats. PxPlus 2026 introduces enhanced security modules, along with a new Authenticator App for Two-Factor Authentication, providing an added layer of protection.  
---|---  
|  In PxPlus 2026, our modernization efforts continue with enhancements that bring greater visual refinement and control to PxPlus applications. Updated controls now include new properties, making it easy to create rounded, modern UI elements.  
|  Building on the .NET interface introduced in 2025 and influenced by valuable feedback from our user community, PxPlus 2026 strengthens the interface with new features designed to make development, debugging, and integration simpler and more efficient.  
|  Since its introduction in PxPlus 2024, the Visual Studio Code Extension continues to evolve with a robust set of new capabilities. With input from our user community, PxPlus 2026 delivers a wide range of enhancements designed to simplify and improve the development experience. Notable updates include enhanced Auto Complete functionality, improved code navigation and support for WindX plug-in connections.  
  
## Major New Features

  * Updated PxPlus Security modules:
    * OpenSSL 3.5.6
    * Curl 8.19.0
    * Updated CA Root Certificates  
  

  * Updated to the latest version of Chromium (*browser)  
  

  * Updated the **[PxPlus SQL ODBC Driver](../odbc/using_odbc_driver.md)** and **[PxPlus SQL Server](../odbc/pxplus_file_server.md)** to use OpenSSL 3.5.6 and added Data Dictionary Hide Table support  
  

  * Introduced new control properties, Corner Radius and Focus Rectangle, to support the creation of rounded UI elements and improve the overall visual presentation of both NOMADS and non-NOMADS applications  
  
  
  

  * Refreshed the Light and Dark mode toolkit themes with updated visuals and new UI elements

## Enhancements

**Directives**

  * **BUTTON, CHECK_BOX and RADIO_BUTTON** directive option
    * Added **OPT= "x"** setting to add a tab close button for a **[Button](../directives/button.htm#Mark27)**, a **[Check Box](../directives/check_box.htm#Mark28)** (with an image) and a **[Radio Button](../directives/radio_button.htm#Mark27)** (with an image)  
  

  * **DEF_OBJECT** directive enhancements
    * Added the ability to **[List Available .NET System DLLs and then Objects](../directives/def_object.htm#Mark17)** via "[.NET]*" and to **[List Available .NET Objects for the Given DLL](../directives/def_object.htm#Mark18)** via "[.NET]dllname,*"

  * **MULTI_LINE** directive option
    * Added **[OPT="m"](../directives/multi_line.htm#Mark27)** setting to vertically center text



**Properties**

Properties can be used to specify settings for NOMADS and non-NOMADS applications.

> **Note:** To use the new Corner Radius properties, **4D** mode is required.

  * **[CBCornerRadius$](../properties/cbcornerradius_.md)** property added to support rounded corners
    * **[Check Boxes](../control_object_properties/checkbox_properties.htm#cbcornerradius)**: Sets the corner radius for standard Check Box controls
    * **[Tri-State Check Boxes](../control_object_properties/tristate_box_properties.htm#cbcornerradius)**: Sets the corner radius for standard Tri-State Check Box controls  
  

  * **[CornerRadius$](../properties/cornerradius_.md)** property added to support rounded corners for controls
    * **[Buttons](../control_object_properties/button_properties.htm#cornerradius)**: Sets the corner radius for Button controls
    * **[Check Boxes](../control_object_properties/checkbox_properties.htm#cornerradius)**: Sets the corner radius for Check Box controls with an image
    * **[Drop Boxes](../control_object_properties/dropbox_properties.htm#cornerradius)**: Sets the corner radius for Drop Box controls
    * **[List Boxes](../control_object_properties/listbox_properties.htm#cornerradius)**: Sets the corner radius for all types of List Box controls except Report View and Variable List Boxes
    * **[Multi-Lines](../control_object_properties/multiline_properties.htm#cornerradius)**: Sets the corner radius for Multi-Line controls
    * **[Radio Buttons](../control_object_properties/radiobutton_properties.htm#cornerradius)**: Sets the corner radius for Radio Button controls with an image
    * **[Tri-State Check Boxes](../control_object_properties/tristate_box_properties.htm#cornerradius)**: Sets the corner radius for Tri-State Check Box controls with an image
    * **[Variable Drop Boxes](../control_object_properties/vardropbox_properties.htm#cornerradius)**: Sets the corner radius for Variable Drop Box controls  
  

  * **[FieldHeight](../properties/fieldheight.md)** property added for **[Drop Box](../control_object_properties/dropbox_properties.htm#fieldheight)** and **[Variable Drop Box](../control_object_properties/vardropbox_properties.htm#fieldheight)** controls to set the height of the drop box input and drop area (in pixels)  
  

  * **[FocusRect](../properties/focusrect.md)** property added to suppress or display the dotted focus rectangle on controls (set by control type)
    * **[Buttons](../control_object_properties/button_properties.htm#focusrect)**: Suppresses or displays the focus rectangle around the Button text
    * **[Check Boxes](../control_object_properties/checkbox_properties.htm#focusrect)** (with and without an image): Suppresses or displays the focus rectangle around the Check Box text
    * **[Drop Boxes](../control_object_properties/dropbox_properties.htm#focusrect)**: Suppresses or displays the focus rectangle around the Drop Box selected text except for Variable Drop Boxes
    * **[List Boxes](../control_object_properties/listbox_properties.htm#focusrect)**: Suppresses or displays the focus rectangle around the selected row for all types of List Box controls except Variable List Boxes
    * **[Radio Buttons](../control_object_properties/radiobutton_properties.htm#focusrect)** (with and without an image): Suppresses or displays the focus rectangle around the Radio Button text
    * **[Tri-State Check Boxes](../control_object_properties/tristate_box_properties.htm#focusrect)** (with and without an image): Suppresses or displays the focus rectangle around the Tri-State Check Box text

**Objects**

  * New **[Parse URL Object](../utilities/obj_parseurl.md)**: Parses values from a specified parameter of a provided URL

  * **[Array List Object](../utilities/obj_arraylist.md)**: New methods added to help with data manipulation
    * **[Clone( )](../utilities/obj_arraylist.htm#clone)**: Returns a handle to an array list with identical values
    * **[Get(_index1, index2_)](../utilities/obj_arraylist.htm#get)**: Gets a subsection of the array list, returned as an array list handle
    * **[Pop( ) / Pop$( )](../utilities/obj_arraylist.htm#pop)**: Gets the last value in the array list and then removes it
    * **[Print( )](../utilities/obj_arraylist.htm#print)**: Prints the string representation of the array list
    * **[Remove_range(_index1, index2_)](../utilities/obj_arraylist.htm#removerange)**: Removes the values within the given range
    * **[Reverse( )](../utilities/obj_arraylist.htm#reverse)**: Reverses the order of the array list
    * **[Set(_array_)](../utilities/obj_arraylist.htm#set)**: Sets array list values to that of the given array list
    * **[Shift( ) / Shift$( )](../utilities/obj_arraylist.htm#shift)**: Gets the first value in the array list and then removes it
    * **[String$( )](../utilities/obj_arraylist.htm#string)**: Returns a string representation of the array list
    * **[Swap(_index1_ , _index2_)](../utilities/obj_arraylist.htm#swap)**: Swaps the values at the given indices  
  

  * **[*Secure Object](../utilities/secure.md)**: New methods and property added to support the **[Authenticator App](../NOMADS%20Graphical%20Application/System%20Maintenance%20Tools/Security%20Manager/Assigning%20Users%20to%20Classifications.htm#authenticator)**
    * **[Secret_Code$(_user_email$_)](../utilities/secure.htm#secret_code)** method: Generates a QR code and produces a Base32-encoded secret
    * **[Totp_Calculation$(_secret$_)](../utilities/secure.htm#totp_calc)** method: Returns the time-based one-time password (TOTP)
    * **[Secret_Encoded$](../utilities/secure.htm#secret_encoded)** property: Contains the generated Base32-encoded secret



**[.NET Interface](../Dot%20Net%20Interface.md) Enhancements**

  * New extended methods for indexed array access across multiple data types (numeric, string, and .NET object handles)

  * Enhanced accessibility to system DLLs and .NET objects
    * Ability to list available .NET system DLLs and their objects

    * **[PvxObjName$](../directives/def_object.htm#Mark20)** property added: Returns the current object name

  * Improved .NET exception error messages
